# lap-counter.py
This is a python script that counts the amount of times a string is entered. This script was made with the Ajfwm RFID scanner (https://a.co/d/0cpPQQAX) in mind but it may be compatible with other hardware and software.
For other RFID readers to be compatible the scanner needs to produce a unique string when an RFID tag is scanned and enter to be pressed or sent. This will then prompt the user for a name to be entered and the counter will start at zero.

This was a solo project from my senior year in highschool
